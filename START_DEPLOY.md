## One-Command Deployment

### If you haven't installed Vercel CLI yet:
```powershell
npm install -g vercel
vercel login
```

### Then deploy:
```powershell
cd c:\projects\SocialServe-Project\social-events-client
vercel --prod
```

That's it! 🎉
