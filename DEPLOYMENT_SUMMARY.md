## 3-Step Deployment Process

### 1. Install Vercel (first time only)
```bash
npm install -g vercel
vercel login
```

### 2. Deploy
```bash
cd c:\projects\SocialServe-Project\social-events-client
vercel --prod
```

### 3. Wait for URL
Vercel will give you your live URL!
